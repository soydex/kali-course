Alors, nous avons déjà vu comment installer Kali Linux dans une machine virtuelle. Kali Linux est la machine que l'on va utiliser comme machine d'attaque. Maintenant, il nous faut une autre machine que l'on va utiliser comme machine victime. Pour cela, je vais utiliser une machine sous Windows 7 Service Pack 1 Ultimate. Vous pouvez également utiliser Windows 10. Il existe des versions spécifiques de Windows 10 que vous pouvez utiliser, qui contiennent des vulnérabilités connues. Je vous laisserai tous les liens dans la description. Donc, si vous voulez faire comme moi, je vous mets le lien pour Windows 7. Si vous préférez essayer avec Windows 10, vous trouverez aussi le lien.

Nous allons utiliser VirtualBox pour installer cette machine, de la même manière que nous l'avons fait avec Kali Linux. Ici, nous allons créer une nouvelle machine que nous allons appeler « Windows 7 victime ». Pour le type, on choisit « Microsoft Windows » et pour la version « Windows 7 (64-bit) ». Pour la RAM, 2 Go sont largement suffisants. Nous cliquons sur « Create a virtual hard disk now ». Nous pouvons lui allouer 50 Go.

Une fois la machine créée, nous allons chercher l'emplacement de notre image ISO de Windows 7 pour la configurer. Dans les paramètres de la machine virtuelle, sous l'onglet « Storage », au niveau de l'emplacement vide (« Empty »), nous cliquons pour sélectionner l'image ISO de Windows.

Ensuite, pour le réseau, assurez-vous que votre Kali Linux et votre machine Windows soient sur le même sous-réseau. Il est très important qu'elles soient sur le même type de réseau, que ce soit en « Bridge Adapter » (Accès par pont) ou en « NAT ». L'essentiel est qu'elles puissent communiquer entre elles. Ensuite, nous allons activer le presse-papier partagé (« Shared Clipboard ») et le glisser-déposer (« Drag'n'Drop ») en mode bidirectionnel. Vous pouvez aussi ajouter des cœurs de processeur si vous le souhaitez, puis cliquer sur « OK ».

Nous lançons ensuite la machine. C'est une installation classique et très simple du système d'exploitation Windows. La machine démarre sur l'ISO. L'installation de Windows 7 est souvent plus rapide que celle de Windows 10, mais cela dépend de la puissance de votre ordinateur.

Nous choisissons la langue d'installation (anglais), le clavier (French) et nous cliquons sur « Next » puis « Install now ». Je choisis la version « Windows 7 Professional ». Nous cliquons sur « Next », acceptons la licence, sélectionnons « Custom (advanced) » et cliquons sur « Next ». Le processus d'installation démarre. Cela va prendre environ 10 à 15 minutes. Le système va ensuite redémarrer et vous arriverez sur le bureau de votre machine Windows 7, que nous utiliserons comme machine victime tout au long de cette formation sur les tests d'intrusion.
