In the previous lesson, we saw how to use Nmap to scan a server or a network, as well as the different arguments necessary to gather information on our target. In this lesson, we will focus on Nessus, a very famous vulnerability scanner, and we will see how to install it. 

First of all, you must go to the official website of Tenable (www.tenable.com), in the download section, to download Nessus. Choose the version for Linux Debian/Ubuntu (AMD64), then start the download. On my side, I performed the download in command line with `wget`, naming the file `nessus_amd64.deb` (it is a Debian package). After the download, I used the command `sudo dpkg -i` (or `sudo apt install ./`) followed by the file name to install it. Once the installation was finished, I started the service with the command `sudo systemctl start nessusd`. I verified that the service was running well with the command `sudo systemctl status nessusd.service`, which confirms that the service is active. 

Then, you just have to open your browser and go to the IP address of your Kali Linux (or `localhost`) on the default port of Nessus, `8834` (in HTTPS, so `https://localhost:8834`). You will arrive at a web interface where Nessus will start downloading and compiling its plugins and dependencies. Warning, this step can be quite long (it took about half an hour on my side). Once this step is completed, you will be able to create your user account. The procedure is very simple and guided. 

After logging in, you will arrive at the main interface of Nessus. To show you the results directly and not waste your time (since scans can be long), I have already configured and launched some analyses. 

To launch a new scan, you just need to click on "New Scan" in the top right. You will then have access to many scan models: "Basic Network Scan" (the basic network scan), "Malware Scan", "Mobile Device Scan" (for mobile devices, requiring the premium version), or even scans targeted at recent flaws like Log4Shell or PrintNightmare. There is also an "Active Directory Starter Scan" model to audit environments based on Microsoft Active Directory. 

For our demonstration, we will use the "Basic Network Scan" model. By clicking on it, you can configure your scan: give it a name (for example "Penetration Testing"), add a description, choose the destination folder ("My Scans" by default), and above all fill in the target IP address or addresses (or the network range). 

You can also adjust advanced parameters, schedule the scan for a specific date, or configure email alerts to be notified at the start or end of the analysis. You will also find options to configure credentials in order to perform a much more precise authenticated scan, or filter detection plugins. For our example, we leave the options by default and click on "Launch" to start the scan.

I have already carried out scans, notably on my demonstration site `hackinggeek.com`. If we click on the results of this scan, in the "Vulnerabilities" tab, Nessus lists all the vulnerabilities detected on the web server. Most of them are simple configuration information, but there is also a critical vulnerability indicating that the PHP version installed on the remote host is no longer supported by the publisher. Nessus also proposes a solution: update PHP to a supported version. This is crucial information. As the administrator of this server, I know that I must immediately proceed with an update.

In the second scan, if we look at the priority threats table (VPR top threats), we can quickly visualize the vulnerabilities classified by danger level: critical, high (High), medium (Medium), low (Low) or simple information (Info). Nessus provides a detailed description and the associated solution for each flaw you click on. 

As you can see, Nessus is an extremely powerful tool to obtain an overview of the security posture of a server or a network. Furthermore, it allows exporting the results. By clicking on the "Export" button then choosing the format (for example PDF or HTML), Nessus automatically generates a clear and structured report that you can provide to your client at the end of your penetration testing. This report classifies the vulnerabilities by severity level (with CVSS severity scores going up to 9.8 or 10 out of 10 for the most serious flaws), and lists the collected information. 

This is why it is very important to integrate a tool like Nessus into your security audits, alongside other scanners like OpenVAS or Nikto. In the next lesson, we will see how to analyze these vulnerabilities and exploit them to penetrate the target system.
