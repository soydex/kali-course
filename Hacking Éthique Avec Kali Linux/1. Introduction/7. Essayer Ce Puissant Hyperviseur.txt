What's going on guys, bienvenue dans cette nouvelle leçon dans laquelle je voulais partager avec vous un truc super important concernant la virtualisation sur les systèmes Windows. Comme vous le savez déjà, en tant que pentesteurs, nous avons besoin de beaucoup de puissance sur nos machines pour virtualiser les différents systèmes d'exploitation et pratiquer sur différents types de machines. Beaucoup d'entre vous m'ont contacté pour me demander une alternative, surtout pour ceux qui n'ont pas assez de ressources physiques pour virtualiser. Certains d'entre vous n'ont que 4 Go ou 8 Go de RAM, ce qui n'est pas idéal pour faire tourner plusieurs machines virtuelles en même temps.

En préparant ma nouvelle formation sur la création d'un lab Active Directory (AD), j'ai travaillé avec Hyper-V, qui est l'hyperviseur natif développé par Microsoft. D'habitude, j'utilise VirtualBox ou parfois VMware. Cette fois-ci, pour cette formation, j'ai utilisé Hyper-V et cela a parfaitement fonctionné. 

Comme vous pouvez le voir ici, j'ai créé plusieurs machines virtuelles (cinq machines au total : deux machines Windows Server, une sous Windows 10, une sous Windows 7 et une sous Linux). Faire tourner toutes ces machines en même temps avec VirtualBox aurait été très difficile, même avec une machine puissante. Je vous recommande donc de vous intéresser à Hyper-V. C'est un hyperviseur intégré par défaut sur les versions professionnelles de Windows. Essayez-le : c'est un hyperviseur qui gère le partage des ressources physiques (notamment la RAM) beaucoup plus efficacement que VirtualBox ou VMware.
