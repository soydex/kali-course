Dans la précédente leçon, nous avons vu comment utiliser Nmap pour scanner un serveur ou un réseau, ainsi que les différents arguments nécessaires pour récolter des informations sur notre cible. Dans cette leçon, nous allons nous intéresser à Nessus, un scanner de vulnérabilités très réputé, et nous allons voir comment l'installer. 

Tout d'abord, vous devez vous rendre sur le site officiel de Tenable (www.tenable.com), dans la section de téléchargement, pour télécharger Nessus. Choisissez la version pour Linux Debian/Ubuntu (AMD64), puis lancez le téléchargement. De mon côté, j'ai effectué le téléchargement en ligne de commande avec `wget`, en nommant le fichier `nessus_amd64.deb` (c'est un paquet Debian). Après le téléchargement, j'ai utilisé la commande `sudo dpkg -i` (ou `sudo apt install ./`) suivie du nom du fichier pour l'installer. Une fois l'installation terminée, j'ai démarré le service avec la commande `sudo systemctl start nessusd`. J'ai vérifié que le service tournait bien avec la commande `sudo systemctl status nessusd.service`, qui confirme que le service est actif. 

Ensuite, il vous suffit d'ouvrir votre navigateur et de vous rendre sur l'adresse IP de votre Kali Linux (ou `localhost`) sur le port par défaut de Nessus, le `8834` (en HTTPS, donc `https://localhost:8834`). Vous arriverez sur une interface web où Nessus commencera à télécharger et compiler ses plugins et dépendances. Attention, cette étape peut être assez longue (cela a pris environ une demi-heure de mon côté). Une fois cette étape franchie, vous pourrez créer votre compte utilisateur. La procédure est très simple et guidée. 

Après vous être connecté, vous arriverez sur l'interface principale de Nessus. Pour vous montrer directement les résultats et ne pas vous faire perdre de temps (les scans pouvant être longs), j'ai déjà configuré et lancé des analyses. 

Pour lancer un nouveau scan, il vous suffit de cliquer sur « New Scan » en haut à droite. Vous aurez alors accès à de nombreux modèles de scan : « Basic Network Scan » (le scan réseau de base), « Malware Scan », « Mobile Device Scan » (pour les appareils mobiles, nécessitant la version premium), ou encore des scans ciblés sur des failles récentes comme Log4Shell ou PrintNightmare. Il y a également un modèle « Active Directory Starter Scan » pour auditer les environnements basés sur Microsoft Active Directory. 

Pour notre démonstration, nous allons utiliser le modèle « Basic Network Scan ». En cliquant dessus, vous pourrez configurer votre scan : lui donner un nom (par exemple « Test d'intrusion »), ajouter une description, choisir le dossier de destination (« My Scans » par défaut), et surtout renseigner la ou les adresses IP cibles (ou la plage réseau). 

Vous pouvez également ajuster des paramètres avancés, planifier le scan à une date précise, ou configurer des alertes e-mail pour être notifié au démarrage ou à la fin de l'analyse. Vous trouverez aussi des options pour configurer des identifiants d'accès (credentials) afin de réaliser un scan authentifié beaucoup plus précis, ou encore filtrer les plugins de détection. Pour notre exemple, nous laissons les options par défaut et cliquons sur « Launch » pour démarrer le scan.

J'ai déjà réalisé des scans, notamment sur mon site de démonstration `hackinggeek.com`. Si l'on clique sur les résultats de ce scan, dans l'onglet « Vulnerabilities », Nessus liste toutes les vulnérabilités détectées sur le serveur web. La plupart d'entre elles sont de simples informations de configuration, mais on y trouve également une vulnérabilité critique indiquant que la version de PHP installée sur l'hôte distant n'est plus supportée par l'éditeur. Nessus propose également une solution : mettre à jour PHP vers une version supportée. C'est une information cruciale. En tant qu'administrateur de ce serveur, je sais que je dois immédiatement procéder à une mise à jour.

Dans le second scan, si l'on regarde le tableau des menaces prioritaires (VPR top threats), on peut visualiser rapidement les vulnérabilités classées par niveau de danger : critique, élevé (High), moyen (Medium), faible (Low) ou simples informations (Info). Nessus fournit une description détaillée et la solution associée pour chaque faille sur laquelle vous cliquez. 

Comme vous pouvez le constater, Nessus est un outil extrêmement puissant pour obtenir une vue d'ensemble de la posture de sécurité d'un serveur ou d'un réseau. De plus, il permet d'exporter les résultats. En cliquant sur le bouton « Export » puis en choisissant le format (par exemple PDF ou HTML), Nessus génère automatiquement un rapport clair et structuré que vous pourrez fournir à votre client à la fin de votre test d'intrusion. Ce rapport classe les vulnérabilités par niveau de sévérité (avec des scores de criticité CVSS pouvant aller jusqu'à 9.8 ou 10 sur 10 pour les failles les plus graves), et liste les informations collectées. 

C'est pour cela qu'il est très important d'intégrer un outil comme Nessus dans vos audits de sécurité, aux côtés d'autres scanners comme OpenVAS ou Nikto. Dans la prochaine leçon, nous verrons comment analyser ces vulnérabilités et les exploiter pour pénétrer le système cible.
